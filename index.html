Algoritmusok

Mi egy algoritmus?

Egy algoritmus az egy probléma megoldására szolgáló véges, egyértelmű lépésekből álló sorozat.

"Követelmények"

Egy algoritmusnak 4 fő követelénye van.

  1. Determinisztikus, ugyanazokkal a bemenetekkel ugyanaz a kimenet jön ki, minden alkalommal.
  2. Nem végtelen. Egy algoritmusnak véges számú instrukciója van. Nem futhat örökké.
  3. Egy utasítást csak egy módon lehet végrehajtani.
  4. Általános, nem specifikus.

Fajtái

Egy algoritmust 3 módon lehet "ábrázolni": mondatos, folyamatábra, és pseudo code. Magyarázatuk és példa:

Mondatos

Egy mondatos algoritmusba az instrukciók számozottan, mondatokba vannak leírva.

Példa mondatos négyzetre emeléshez:

  1. Kérjük be a négyzet alapot (alap).
  2. Legyen a négyzet egyenlő alap * alappal.
  3. Írjuk ki a négyzetet.
  4. Vége

Folyamat ábra

Ez egy rajz, ahol jelek és ábrák használatával lehet jelölni az algoritmus menetét.

Példa folyamatábra négyzetre emeléshez:

Start
Be: Alap
Négyzet <- Alap * Alap
Ki: Négyzet
End

Pseudo code

Ez egy olyan módja az algoritmusok megjelenítésére amely bármilyen programozási nyelvbe átirható, és legjobban hasonlít írt kódra.

Példa pseudo hatványozáshoz:

be: alap
be: kitevő

ha kitevő = 0 akkor
	ki: 1
különben ha kitevő = 1 akkor
	ki: alap
különben ha kitevő = -1 akkor
	reciprok <- 1 / alap
	ki: reciprok
különben ha kitevő > 0 akkor
	eredmény <- alap
	ciklus i <- 2-től kitevő-ig
		eredmény <- eredmény * alap
	ciklus vége
	ki: eredmény
különben
	eredmény <- alap
	ciklus i <- kitevő-től -2-ig
		eredmény <- eredmény * alap
	ciklus vége
	reciprok <- 1 / eredmény
	ki: reciprok
elágazás vége
